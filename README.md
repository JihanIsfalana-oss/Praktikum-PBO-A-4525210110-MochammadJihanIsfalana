# Praktikum PBO - A

Repositori ini berisi kumpulan tugas dan latihan Praktikum Pemrograman
Berorientasi Objek (PBO), mulai dari materi dasar hingga penerapannya dalam
proyek aplikasi penyewaan kos.

## Materi yang Dipelajari

1. Penggunaan Git dan GitHub untuk pengelolaan versi dan kolaborasi.
2. Dasar pemrograman berorientasi objek, kelas dan objek, enkapsulasi,
   validasi data, serta penjagaan *invariant*.
3. Konstruktor, atribut dan method `static`, konstanta, dan validasi objek.
4. Pewarisan (*inheritance*), penggunaan kelas induk, dan *method overriding*.
5. Polimorfisme, kelas abstrak, dan penerapan prinsip *open/closed*.
6. Abstraksi melalui *abstract class*, *interface*, *enum*, serta *trait*.
7. Relasi objek, termasuk komposisi dan agregasi, serta pengelolaan objek
   melalui kelas layanan.
8. Penerapan konsep PBO pada studi kasus aplikasi penyewaan kos.

## Bahasa Pemrograman
